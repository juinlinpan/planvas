# Planvas AI

This package teaches AI coding tools how to read and update local Planvas whiteboard projects.

Use `skills/planvas-skill/SKILL.md` for workflow selection. Load only the needed reference:

- `references/read-page.md`: read pages, summarize boards, update external tickets from page meaning.
- `references/mcp-tools.md`: call Planvas MCP tools.
- `references/xml-write-schema.md`: direct XML fallback, schema repair, or persistence implementation work.

Default MCP SSE endpoint: `http://127.0.0.1:18001/sse`.
